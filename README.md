# ECHOS OF THE ETERNAL

Strategic collectible card battler with clear tabletop-like rules, strong board presence and a creator/admin pipeline for Ø to design, balance, patch and publish cards.

## Unreal foundation
Narrative Pro 2 + Ultra Game Template 1.3 where useful for shell/story/account flow, while **Card Creator Pro + Card Games Templates + Card Game Interface** are evaluated as the primary card-game accelerators. Canonical ECHOS rules/data always supersede template assumptions.

## Companion admin app
Separate first-class admin/content application: card database, Canva/source-art import, card template renderer, sets, rarity, legality, limits/bans, patches, balance/version history, release scheduling and asset validation.

## Gates
V1: complete rules engine, deck builder, match, card pipeline/admin, AI opponent, save/account. V2: online multiplayer/ranked/tournaments/content operations. V3: expanded formats/social/economy/AXIOM/PYRAMID integration.
